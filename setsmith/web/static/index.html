Set up discovery

Discover finds tracks you don't own through Last.fm (similar tracks and artists) and GetSongBPM (BPM and key), using your own free API keys. BPM and key GetSongBPM doesn't know are estimated from Deezer's 30-second previews (needs the audio extra).

  1. Create a Last.fm API key at last.fm/api, then run setsmith keys set lastfm YOUR_KEY.
  2. Optional but recommended, for BPM and key: get a key at getsongbpm.com/api, then run setsmith keys set getsongbpm YOUR_KEY.
  3. Restart setsmith web.
